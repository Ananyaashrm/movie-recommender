# Movie Recommendation System

A content-based movie recommendation system built using Python, Pandas, Scikit-Learn, NLP preprocessing, CountVectorizer, cosine similarity, and fuzzy matching.

## Features
- Content-based recommendations
- NLP preprocessing and stemming
- Cosine similarity matching
- Fuzzy search for misspelled movie titles
- Dataset of 4800+ movies

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-Learn
- NLTK

## Dataset
TMDB 5000 Movies Dataset

## Example

Input:
Avatar

Output:
- Guardians of the Galaxy
- John Carter
- Star Trek
- Aliens
- Titan A.E.
